# ZENVORA

ZENVORA is a static online store demo with:

- Homepage and product catalog
- Search and filters
- Product details and reviews
- Cart and checkout
- Login/register
- User orders
- Owner admin database for products, inventory, sold-out status, and received orders

## Owner Setup

Open the deployed site and go to `Admin DB`. Create the owner account in your browser. No fixed admin password is stored in this public repository.

## Data Note

This demo stores users, products, inventory, carts, orders, and reviews in browser `localStorage`. For a real store shared by all customers, connect the frontend to a backend such as Firebase, Supabase, MySQL, or MongoDB.
